## PRINCIPLES I BUILD BY

- **Clarity over Cleverness** – Readable, debuggable and maintainable code wins every time.
- **Simplicity Scales** – The best solutions are often the simplest ones that actually work.
- **Security by Design** – Treat inputs, auth, data and secrets with zero assumptions.
- **Measure, Then Optimize** – Data-driven decisions over premature optimization.
- **Fail Fast, Recover Gracefully** – Resilient systems that degrade safely under pressure.
- **Documentation as a Product** – If it's not documented, it doesn't exist for the next engineer.
- **Ownership Mindset** – I treat every product I build as if it were my own.
